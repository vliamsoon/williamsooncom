# William Soon — AI Training website

This is a static website. It does not require npm, a build command, or environment variables.

## Deploy with Vercel

1. In Vercel, choose **Add New → Project** and import the GitHub repository.
2. Use the repository root as the Root Directory.
3. Set Framework Preset to **Other** (or leave it auto-detected), leave the Build Command blank, and deploy.
4. Confirm the home page, project image previews, certificate preview, video, and WhatsApp links on the Vercel URL.

The images and certificate in `assets/` are served publicly after deployment. No private deployment token or temporary Vercel metadata is included in this ZIP.
